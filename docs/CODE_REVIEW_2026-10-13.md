# Проверка действующего сервиса — 13 октября 2026

Проверены backend, frontend, миграции, очередь, обмен и конфигурация запуска. Прежний автономный загрузчик в корне репозитория сохранён как архивный код; Compose его не использует. Его не следует запускать вместе с действующим сервисом.

## Исправления

| Ошибка | Исправление |
|---|---|
| Файл перемещён на Диске, процесс прервался до сохранения пути, затем оператор изменил дату: сервис мог потерять расположение оригинала | Загрузка и перемещение используют заранее сохранённое назначение. Повтор сначала восстанавливает прежнюю операцию, затем применяет актуальную карточку. Тот же механизм используется при переносе учебного архива |
| После успешной загрузки и сбоя до фиксации пути новое редактирование могло оставить лишний оригинал | Прежняя загрузка завершается по сохранённому пути, затем оригинал перемещается; локальные байты сверяются с SHA256 до загрузки |
| Старая задача публикации могла возобновить уже убранный JSON | Завершённые, удалённые и очищаемые публикации не публикуются повторно |
| Одна фотография в тестовом и рабочем режимах дважды учитывалась в обучении | Учебная выборка объединяется по SHA256; одинаковые изображения с противоречащими метками исключаются до исправления разметки |
| Ответ MAX мог содержать «Принято» при статусе ERROR | Для ошибки обработки или хранения используется отдельный ответ |
| При исчезновении папки между страницами её списка очистка могла продолжиться с неполными сведениями | Изменение количества файлов или исчезновение папки при обходе останавливает очистку до удаления |
| Открытие удалённого оригинала давало внутреннюю ошибку сервиса | Ответ 409 с объяснением для отсутствующего файла, 502 для недоступного Диска; сведения внешнего запроса не раскрываются |
| Административный повтор задачи мог изменить состояние одновременно с работником | Перед проверкой и изменением состояния строка задачи блокируется; повтор завершённой или уже выполняемой задачи отклоняется |
| Возврат из карточки терял «За всё время»; миниатюра и кнопка «Открыть» передавали разные фильтры | Общая функция ссылки сохраняет период, фильтры и режим проверки |
| Поздний ответ загрузки предыдущей карточки мог перезаписать новую | Применяется только ответ актуального запроса |

Убраны дублирование переноса учебных фото, отдельный цикл ожидания операции Диска и повторная проверка состояния очереди. Изменённые Python-файлы отформатированы. Существующие 16 маркировок, обучение, ручная публикация и раздельные папки JSON/фото сохранены.

## Проверки

- Backend: **226 passed, 13 skipped** на отдельной PostgreSQL/PostGIS. Проверены миграции до `0008`, авторизация и права, приём/дедупликация, ручная проверка/спам, отчёты, хранение, обучение, версии и поколения JSON, повторы после сбоев.
- Эти 13 пропусков обусловлены отсутствием Tesseract на macOS. Все **13 соответствующих OCR-сценариев отдельно прошли в контейнере с настоящим Tesseract без сети**: русская дата, синтетическая надпись и контрольные фото, включая №74, в нескольких размерах.
- Frontend: **8 тестов прошли**, TypeScript и сборка Vite прошли.
- Ruff и `git diff --check` прошли.
- Браузер: вход во временную локальную панель, список, выбор «За всё время», открытие через кнопку и миниатюру, возврат с сохранением периода. Ошибок и предупреждений в консоли при этой проверке нет.
- Добавлены проверки MAX polling: повтор страницы без дублей, откат всей страницы и маркера при сбое, успешное продолжение и отказ от polling при зарегистрированном webhook.

Внешние ответы MAX и Яндекс.Диска в автоматических тестах имитируются. Рабочие токены и сервер при этой проверке не использовались, сообщения в MAX не отправлялись, файлы на рабочем Диске не перемещались. Реальное подключение, права читателя АРМ и совместимость с его загрузчиком подтверждаются на рабочем стенде по `ACCEPTANCE.md` и документации обмена.

Изменения находятся в исходниках. Для применения требуется обновить API, worker, publisher и web; миграция `0008` из предыдущей доработки также должна быть установлена. Дополнительная миграция для описанных исправлений не нужна.
