# Проверка от 20.10.2026

Проверены доработка закрытия дней и привычное табличное представление фотографий.

## Автоматические проверки

- Полный backend-набор в Linux / Python 3.12 с PostgreSQL 16, PostGIS 3.5,
  Tesseract и проверенными OCR-моделями: **848 пройдено, 0 ошибок, 0 пропусков**.
- Frontend: **122 теста пройдено**, TypeScript и производственная сборка Vite успешны.
- Ruff и проверка пробелов в изменениях успешны. Единственная вершина миграций — `0028`.

Для backend использовалась отдельная временная PostgreSQL/PostGIS. База для тестов
и база предпросмотра разделены. Рабочие контейнеры, их базы и хранилища не запускались
и не подключались к тестам. Проверяемые исходники и документация подключались
к тестовому Linux-контейнеру только для чтения.

Полный прогон включает миграции, географию, ограничения чатов, права операторов,
проверку и закрытие дней, поздние поступления, отчёты и экспорт, хранение файлов,
обмен, обучение и регрессии распознавания даты/времени/координат на реальных
тестовых изображениях. Документированные схемы и примеры обмена также проверены.

## Проверка интерфейса на PostgreSQL

На вымышленных данных проверены:

1. Таблица в «Проверке дней» использует тот же компонент и оформление, что архив
   «Фотографии»: миниатюры, даты съёмки и получения, чат, микрорайон, координаты,
   вид работы, неисправность, статус, уверенность, оператор и открытие карточки.
2. Отметка неисправности сохраняется из строки и обновляет набор для подтверждения.
3. «Сохранить и перейти дальше» переходит с фото 71 на 72 по текущей очереди.
   Ручное решение исчезает из повторной проверки нейросети.
4. Подтверждение включает два решения нейросети и одно ручное дополнение:
   число проверенных увеличивается с 3 до 6, очередь становится пустой.
5. После ещё трёх поступлений за прежнюю дату остаются 6 проверенных фото,
   а в новой очереди отображаются только 3 новых снимка.

Установка на сервер выполняется отдельно: обновление API и интерфейса с миграцией
`0028`. Предпросмотр и тестовый прогон не изменяют рабочую установку.
