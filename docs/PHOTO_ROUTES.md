# Маршруты по фотографиям

Раздел `/photo-routes` оценивает обход по фотографиям из выбранных чатов MAX. Трекеры и Wialon не используются. Существующие фотографии, границы и обработка сообщений не изменяются.

## Настройка

1. Создайте границы территории в разделе «Микрорайоны», если они ещё не добавлены.
2. Откройте «Маршруты по фото», выберите территорию и нажмите «Отметить маршрут».
3. Выберите чаты, для которых нужен расчёт. По умолчанию функция выключена.
4. Загрузите контуры домов из OpenStreetMap и дополните отсутствующие контуры вручную. Загрузка меняет только черновик; сохранение выполняется отдельно. Пустая карта не доказывает отсутствие зданий.
5. Добавляйте обязательные участки точками на карте по дорогам и проходам, обходя здания. Завершайте каждый участок отдельно. Разные территории имеют отдельные планы.
6. Проверьте контуры домов и маршрут, включите расчёт и сохраните. При пересечении здания или выходе за границу сохранение будет отклонено. Проверяется вся линия, включая отрезки между вершинами.

Настройка доступна администратору; просмотр — пользователям с правом просмотра фотографий и доступом к выбранным чатам. Настройки хранятся в базе текущей организации. Изменение плана не меняет фотографии и не отправляет сообщения в MAX.

## Расчёт

Процент оставшегося пути = уникальная непройденная длина / уникальная длина отмеченного маршрута × 100. Это длина линий, а не площадь территории. Здания не входят в маршрут. Совпадающие участки и повторные проходы не увеличивают итог.

Можно выбрать один день или период до 31 дня. За период выполненные участки объединяются; фотографии разных дней не соединяются. Для выбранной территории строится свой граф. Между разными чатами и авторами снимков связей нет. Между соседними подходящими фотографиями выбирается кратчайший путь по отмеченному графу. Прямые срезы через двор, дом или за границу не добавляются.

Используются только принятые фотографии текущего режима приёма с известными координатами, автором, датой и временем съёмки. Дата получения не подменяет время съёмки. Если время хотя бы одного снимка автора в чате за день неизвестно, траектория этой группы не восстанавливается: порядок снимков недостоверен. Точки снаружи территории, внутри зданий, за допустимым отклонением от маршрута или без координат прерывают последовательность. Допуск по умолчанию — 25 м; промежуток между фотографиями — не более 45 минут. Оба значения настраиваются. Привязка точки к маршруту также не может пересекать здание или границу.

**Это оценка по фотографиям, а не запись фактического движения.** Между редкими снимками реальный путь неизвестен; на развилке мог быть выбран другой вариант. Одиночный снимок сам по себе не подтверждает проход участка. Полнота исключения домов зависит от проверенных контуров. Система не определяет невнесённые здания по изображению подложки.

Максимум 5000 фотографий за запрос; при превышении нужно уменьшить период или выбрать один чат. Длина измеряется в метрах в локальной проекции территории; модуль предназначен для городских территорий, первоначально Нефтеюганска. При изменении границ территория и сохранённый маршрут проверяются заново. При одновременном редактировании устаревшее сохранение отклоняется.

## Локальная установка

Добавлена миграция `0049_photo_routes`, создающая только таблицу `photo_route_plans`. В базе с другой экспериментальной миграцией `0049` (старый модуль транспорта) нельзя считать версии взаимозаменяемыми: для локального просмотра используется отдельная база `photo_routes_local`. На рабочий сервер изменения автоматически не устанавливаются.

Для просмотра настоящего прогресса нужны настоящие границы, фотографии и отмеченный план в выбранной базе. В пустой локальной базе прогресс не выдумывается.
