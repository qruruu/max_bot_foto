# Обезличенные счётчики открытий страниц

Оба веб-сервиса пишут дополнительный формат `METKA_USAGE_V1`: время, фиксированная
категория страницы и фиксированная категория источника. Никакие IP, аккаунты,
география, query, полные пути, Referer или User-Agent в этот формат не входят.
Отдельного публичного API мониторинга нет.

Считаются успешные GET HTML-навигации (200/304) по известным страницам, включая
повторные загрузки. API, статические ресурсы, неизвестные адреса и служебные файлы
исключены. Признак документа берётся из Sec-Fetch-Dest либо Accept: text/html для
старых браузеров. Источник берётся из Referer и может отсутствовать или быть подделан.
Это число открытий страниц, а не уникальные посетители, сеансы или все переходы SPA.

Закрытый сборщик «Метка Монитор» читает журнал, удаляет повторные события и хранит
зашифрованные часовые счётчики; отображает календарные дни Екатеринбурга и источники
за семь дней. История начинается с подключения. География не собирается.

Проверка обеих настоящих Nginx-конфигураций: `python3 ops/test_web_security.py`.
Проверяются классификация источника, отсутствие секретных полей, исключение API и
ресурсов, а также сохранение защиты служебных файлов и обычных маршрутов.
