# Приёмка на реальных аккаунтах

Автотесты используют PostgreSQL/PostGIS и имитацию внешних ответов только внутри `backend/tests`. Рабочие интеграции приложения не используют тестовые реализации. Создание бота/аккаунтов, серверный домен и токены настраиваются владельцем; автоматически при разработке рабочим чатам сообщения не отправляются.

## Перед тестом

1. Заполнены MAX_BOT_TOKEN, MAX_WEBHOOK_SECRET, YANDEX_DISK_TOKEN, YANDEX_MAPS_API_KEY; MAX_VERIFY_TLS=false.
2. Работает HTTPS; APP_ENV=production и COOKIE_SECURE=true.
3. Администратор создан CLI, добавлен отдельный тестовый MAX-чат, нарисованы его реальные полигоны.
4. Выполнена регистрация webhook. API, worker и trainer запущены, временное хранилище постоянно.

## Сценарии

| Действие | Ожидаемый результат |
|---|---|
| Отправить снимок из разрешённого чата | Появляется запись, оригинал на Яндекс.Диске, ответ MAX |
| Отправить тот же файл из другого разрешённого чата | DUPLICATE, без второго файла и OCR/AI |
| Переслать снимок | FORWARDED; файл не скачивается, не сохраняется |
| Отправить PDF / повреждённый JPEG | Разные корректные причины отказа |
| Отправить оригинал HEIC/TIFF/GIF | Оригинал не меняется; анализ конвертированной копии/первого кадра |
| Отправить 3 вложения одним сообщением, одно — дубль | Один ответ с итогами 3/2/1 |
| Отключить чат в панели | Новые события из него игнорируются |
| Снимок без даты/координат | NEEDS_REVIEW, оригинал сохранён, без сообщения об операторе в MAX |
| Снимок с неоднозначной работой | Один итоговый вид не назначается; варианты и ответ AI сохраняются |
| Исправить дату, координаты и работу | Аудит, пересчёт микрорайона, перенос на Диске, следующая карточка |
| Открыть одну карточку двумя операторами | Второе сохранение устаревшей версии получает 409 |
| Точка за границами / в пересечении | NEEDS_REVIEW; микрорайон не угадывается |
| Изменить название или границы территории | Существующие фото пересчитываются, пути синхронизируются |
| Остановить worker после скачивания, запустить | Задача продолжается, оригинал сохранён |
| Временно отключить Диск | ERROR, буфер не очищается; после восстановления SYNC |
| Временно отключить OCR/локальную модель | Фото на Диске, NEEDS_REVIEW; ручной ввод доступен |
| Скачать Excel с несколькими фильтрами | Число строк и сводные листы совпадают с панелью |
| Войти как OPERATOR | Отчёты/проверка доступны, пользователи/чаты/границы недоступны для изменения |
| Заблокировать оператора | Его существующая сессия перестаёт работать |

Для оценки OCR/локальную модель соберите согласованную выборку реальных кадров каждого из 16 видов работ, разных сезонов и штампов. Сверьте дату/координаты и долю верных автоматических назначений с ручной разметкой; подберите порог уверенности. Не используйте синтетические изображения как доказательство качества распознавания производственных кадров.

## Карта и обучение

- На Яндекс.Карте нарисовать два отдельных контура одного микрорайона, изменить вершины, сохранить и открыть повторно. Проверить точку с известными долготой/широтой. Для рабочего отображения нужен действующий ключ с разрешённым доменом.
- Без обученной модели фото получает WORK_UNCERTAIN, результат содержит MODEL_NOT_TRAINED. Никаких исходящих запросов с фото к ChatGPT/AI-провайдеру нет.
- Разметить реальные фото, достичь порогов, проверить автоматическое задание TRAIN. Учитываются только подтверждения вида работы, а не собственные прогнозы модели.
- На странице обучения проверить число обучающих/проверочных снимков, метрики и статус. При неудовлетворительной оценке версия REJECTED, рабочая версия остаётся прежней.
- После новых решений оператора проверить повторное обучение и смену активной версии при прохождении порогов. Исправленная метка учитывается как изменение, повторное сохранение прежней — нет.
- Перезапустить trainer во время цикла; незавершённая версия помечается INTERRUPTED, задача возобновляется. Приём фотографий продолжает работать.

Автотест проверяет реальный градиент и сохранение/загрузку ResNet18, а весь цикл обучения/активации дополнительно прогоняет на маленькой тестовой сети. Это проверка механизма, не доказательство распознавания 16 производственных работ. Размеченных производственных фотографий и обученной на них версии в репозиторий не добавлялось.
